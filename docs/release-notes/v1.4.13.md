## New features

* **The Astera SDK is on npm.** `npm install @astera-app/client` installs the client, and
  `npm install @astera-app/plugin-sdk` the helpers for writing plugins. There is no need to build them from this
  repository any more. [docs/sdk.md](https://github.com/parsingk/Astera/blob/main/docs/sdk.md) and
  [docs/plugins.md](https://github.com/parsingk/Astera/blob/main/docs/plugins.md) are the guides.
* **Session events in the public event log.** A program that follows the Host's event log now also hears when a
  session waits for you to answer a permission or a question, when it stops at a usage limit, and when Account
  Rolling moves it to another account. These are the moments Astera's own desktop notifications announce. They need
  `@astera-app/client` 0.2.0.
* **Folder links in the terminal.** A folder an agent prints is now a link. A folder of the project the explorer shows
  opens there, expanded and selected; any other folder opens in your system's file manager.
* **Quoted paths with spaces are links.** A path in quotes, such as `"C:\My Files\report.png"`, is now a link as a
  whole.

## Fixes

* **A file name with a word glued to it is still a link.** When an agent wrote a Korean, Japanese or Chinese word
  right after a file name (`image.png는`), or a `!`, `?`, `~` or `…`, the name stopped being a link. It now links to
  the file, and a word glued after a web address is no longer taken as part of it either.
* **A path glued to what comes before it is a link.** A path right after a word, `=`, a bracket of either width, or
  inside Markdown such as `![image](path)` or `[text](path)`, was not found. It is now, and of two links that overlap,
  the longer one wins.
* **A path cut across lines joins up with Korean folder names.** When a long path was cut at the edge of the terminal
  inside a Korean folder name, its two halves did not join into one link. They now do.
* **A file written after its name is printed links sooner.** A name the terminal could not find is looked up again
  after 2 seconds instead of 5.
