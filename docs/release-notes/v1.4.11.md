## New features

* **Turn Remote Runtime on, pair and unpair from Settings.** Settings › Remote Runtimes › This computer now does what
  needed the command line before. Choose the address to accept connections on (this computer's LAN or Tailscale
  addresses, or this computer only) and turn it on or off. Make a pairing string, read-only or full control, with a
  name. It shows the time left and a copy button, and a warning when it gives full control. The paired controllers are
  listed with an Unpair button, also while Remote is off. Turning it off keeps the pairings and spends any pairing
  string not used yet.
* **Images and videos open from the file explorer.** Double-clicking an image or a video in the explorer, or clicking
  one linked from a Markdown preview, opens it in the media viewer, as a link in a terminal does. Before, it opened a
  file tab that said binary files cannot be shown. avif, bmp and ico open in the viewer too. A media tab follows a
  rename or a move in the explorer and closes when the file is deleted.

## Fixes

* **Long file paths in a terminal are links again.** Claude Code wraps a long line itself and indents what follows,
  so a long path cut across rows was not a link: only some of a list of paths opened, and almost none in a split pane.
  A path cut that way is now one link from any of its rows, when it names a file.
* **Checklist lines show their text in the Markdown preview.** A task list line (`- [ ] ...`) showed only its
  checkbox. Its text now shows beside the box, and a long line wraps under its own text.
