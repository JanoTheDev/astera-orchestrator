## New features

* **A remote terminal session fits the screen of whoever typed last.** A terminal session open both on a Runtime and
  on a controller has one size. It now follows the side that typed last: type on your laptop and it fits your laptop's
  window, type at the Runtime and it fits that window. The other side shows the whole screen at a smaller font with a
  note saying whose window it follows, instead of cutting off the bottom rows where Claude's prompt is. Before, a
  session also shown in the Runtime's own app kept that app's size, and the controller lost the prompt below its
  window.

## Fixes

* **Sessions no longer end when the app starts while the Host runs.** v1.4.9 shipped a list of the Host's files that
  named one file the installer leaves out, so every app start found the Host's runtime incomplete and tried to
  replace it. On Windows that removed every file the running Host had not locked, and the Host ended at the next file
  it needed, with every session in it. The list now matches what is installed, and a runtime a Host is running from
  is never removed.
* **A Host that stops unexpectedly leaves the reason behind.** An error the Host could not handle is now written to
  its log before it exits, and anything it prints on the way out goes to `host-stderr.log` beside it.
* **The Korean screens say 페어링.** Settings › Remote Runtimes and the remote session screens used 짝짓기 next to
  페어링 for the same thing; they now say 페어링 throughout.
