# Product docs

For a buyer, a pricing page, or whoever decides what Astera sells. These pages describe the app as it is on the branch,
and every claim names where it was checked.

- [Features](features.md): what the app does, grouped by buyer value, with where each feature lives and a
  `core` / `pro candidate` tag for a pricing page.
- [Known limits](known-limits.md): platforms (Linux verified; Windows and macOS built, not verified), required tools and
  accounts, permissions, rate limits, network use, reason lines that stay in English, and open defects.
- [Licensing](licensing.md): the seam where paid licensing will plug in (the About page License row). No licensing code
  exists yet.

Developer docs stay in [docs/dev/](../dev/). User guides are [docs/guide.md](../guide.md) and
[docs/usage-guide.md](../usage-guide.md).
